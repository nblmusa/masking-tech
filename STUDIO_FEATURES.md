# Studio Page Features

## Overview
The Studio page provides advanced image editing and privacy protection capabilities with an intuitive interface for processing images.

## Core Features

### 1. Image Upload
- Drag and drop interface for easy image upload
- Supports JPG, PNG, and WebP formats
- Automatic image preview and validation

### 2. Detection Types
- **Face Detection**: Automatically detect and mask faces in images
- **License Plate Detection**: Identify and mask license plates for privacy
- **Car Detection**: Detect vehicles for background removal/replacement

### 3. Masking Styles
- **Blur**: Apply customizable blur effects with adjustable radius and opacity
- **Solid**: Replace detected areas with solid colors and opacity control
- **Logo**: Overlay custom logos with position, size, and opacity settings

### 4. Background Replacement (NEW!)
- **Predefined Templates**: Choose from 3 professional background templates:
  - Office: Professional office environment
  - Nature: Natural outdoor settings
  - Urban: City and urban landscapes
- **Custom Backgrounds**: Upload your own background images
- **Adjustable Settings**: Control opacity and blur effects
- **Smart Integration**: Works seamlessly with car detection and background removal

### 5. Watermarking
- Custom text watermarks
- Position control (5 positions: top-left, top-right, center, bottom-left, bottom-right)
- Style customization (color, size, opacity)
- Real-time preview

### 6. Background Removal
- Advanced car background removal
- Refinement levels (fast, balanced, detailed)
- Shadow preservation options
- Background color selection

## User Interface

### Feature Summary
- Real-time display of active features
- Visual indicators for enabled detection types
- Quick overview of processing capabilities

### Keyboard Shortcuts
- `Ctrl+D`: Switch to Detection tab
- `Ctrl+M`: Switch to Masking tab
- `Ctrl+B`: Switch to Background tab
- `Ctrl+W`: Switch to Watermark tab
- `Ctrl+R`: Reset all settings

### Quick Actions
- One-click enable/disable of related features
- Smart suggestions for optimal feature combinations
- Contextual help and tips

## Processing Workflow

1. **Upload Image**: Drag and drop or click to select
2. **Configure Detection**: Choose what to detect (faces, plates, cars)
3. **Select Masking**: Choose blur, solid, or logo masking
4. **Background Options**: Remove or replace backgrounds
5. **Add Watermarks**: Optional text overlays
6. **Process**: Apply all settings and generate result
7. **Download**: Save the processed image

## Technical Features

- Real-time preview with split-view comparison
- Detection area indicators
- Responsive design for all screen sizes
- Optimized for performance with large images
- Integration with backend processing API

## Best Practices

- **For Privacy Protection**: Enable face and license plate detection with blur masking
- **For Product Photography**: Use car detection with background replacement
- **For Branding**: Combine logo masking with watermark features
- **For Professional Use**: Enable all detection types with balanced refinement
